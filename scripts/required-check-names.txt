#    required 는 **영구 pending** 이 되어 `main` 이 모든 PR 에서 BLOCKED 된다.
#    그 리네임 PR 자신은 **초록으로 머지된다** — 자기를 막지 못한다.
#
# 🔵 `changes` 만 짧은 이유: 그 job 에는 `name:` 이 없어서 **job id 가 그대로 context**
#    가 된다. 괄호가 «생략 가능» 한 것이 아니다 — 나머지 셋은 **다른 문자열**이다.

#    만든다.** `ci.yml` 을 보고 채우지 마라 — 그러면 핀이 결함을 얼린다.
