# 🔴 어떻게 발견됐나 — 포트폴리오용 캡처를 «눈으로 보다가»

`TASK-MONO-648` 이 취업 자료용으로 콘솔 전 페이지를 찍었다. `/erp/masters` 는 그중
**론처 카드 4장에 뽑힌 장**(2026-09-09 소유자 승인)이라 실제로 열어 봤고, 거기서 나왔다.

🔴🔴 **자동 판정은 이것을 못 잡았다.** 648 의 캡처 스크립트는 본문에 `empty`/`degraded`
표지를 붙이는데, 이 화면은 **둘 다 아니다** — 글자가 가득 차 있고 표도 5개가 다 찼다.
표지는 「글자가 있나」를 묻고 「무엇이 그려졌나」는 못 묻는다. 🔵 **큐레이션에 사람 눈이
필요한 이유가 이 티켓이다.**

## 🔴🔴 데이터가 없어서가 아니다 — **바로 옆 화면이 이름으로 그린다**

같은 도메인 · 같은 테넌트 · 같은 세션에서 찍은 `/erp/orgview`:

```
EMP-0002  이운영  ACTIVE  DEPT-HQ · 본사 › DEPT-OPS · 운영본부  CC-OPS · 운영 코스트센터  JG-G2 · 대리
```

그 표현(`CODE · 이름`)을 **이미 정해 두었다.** 마스터 화면만 그것을 안 쓴다.

# 🔴 아직 안 정한 것 — 구현자가 고르지 말고 **근거를 적고** 고른다

이름을 어디서 얻을 것인가. 셋 다 성립하고 대가가 다르다:

| | 방법 | 좋은 점 | 나쁜 점 |
|---|---|---|---|
| **A** | **같은 페이지에 이미 로드된 목록에서 조회** | 🔵 부서의 상위 부서는 **같은 표 안에 있다.** 네트워크 0, 계약 변경 0 | 🔴 페이지네이션을 넘어가면 못 찾는다(부서 3건이라 오늘은 안 보이는 함정) · 비용센터→부서처럼 **다른 표**를 참조하는 칸엔 그 표가 로드돼 있어야 한다 |
| **B** | 마스터 API 응답에 `parentName` 등을 **추가** | 화면이 단순해진다 | 🔴 **계약 변경** — `specs/contracts/` 를 먼저 고쳐야 한다(CLAUDE.md) |
| **C** | `orgview` read-model 을 마스터 화면에서도 소비 | 이미 이름을 준다 | 🔴 **eventually-consistent** 다(화면에 배너가 그렇게 적혀 있다). 마스터는 «권위» 화면이라 성질이 다르다 — `/erp/orgview` 안내문이 *"권위 데이터는 「마스터」 화면에서 조회합니다"* 라고 못 박는다 |

🔴🔴 **C 는 함정으로 보인다** — 제품이 이미 「권위 vs read-model」을 갈라 놓았는데 그것을
되섞는 것이다. **A 가 가장 작고 B 가 가장 옳아 보이지만, 판단은 계약을 열어 본 뒤에 한다.**
(분석=Opus 5; 이 표는 코드를 읽고 만든 것이고 계약 파일은 **아직 안 열었다**.)

# Edge Cases

- **`parentId = null`(최상위 부서)** — 지금도 `—` 다. 그대로 둔다.
- **이름을 못 찾았다** — 🔴 **id 로 조용히 되돌아가지 마라.** 그러면 결함이 «가끔»
  되살아나고 그때는 아무도 안 본다. 못 찾았다는 것을 보이게 하라.
- **페이지네이션 밖의 참조**(방법 A 의 함정) — 부서가 3건이라 **오늘은 안 보인다.**
  🔴 부서가 늘면 나타나는 부류이므로, A 를 고르면 이 경우의 처리를 명시하라.
- **폐기된(retired) 참조 대상** — 이름이 있지만 유효기간이 지났다. `orgview` 가 이것을
  어떻게 표시하는지 **먼저 보고** 같게 한다.
- **`asOf` 과거 조회** — 그 시점의 이름이어야 하는가, 현재 이름이어야 하는가.
  🔴 E3 effective-dating 화면이므로 **이것은 진짜 질문이다.** 답을 적어라.

# Failure Scenarios

1. 🔴🔴 **목록 화면 3곳만 고치고 상세 5곳을 남긴다.** 상세는 덜 열려서 오래 산다.
2. 🔴 **`orgview` 와 다른 포맷을 새로 만든다.** 같은 개념에 두 표현이 생기고 다음엔
   한쪽만 고쳐진다.
3. 🔴 **read-model(`orgview`)을 마스터 화면에서 소비한다.** 제품이 갈라 둔 «권위 vs
   eventually-consistent» 를 되섞는다 — `/erp/orgview` 안내문이 명시적으로 반대한다.
4. **가드가 공허하게 초록이다** — 픽스처에 참조 셀이 없으면 아무것도 안 보고 통과한다.
5. 🔴 **고치고 나서 `TASK-MONO-648` 에 안 알린다.** 론처에 걸릴 그림에 UUID 가 박힌 채
   남는다 — 하필 취업 자료의 첫 화면이다.
