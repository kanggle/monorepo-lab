| 데이터가 없는 목록 | 빈 상태도 제품의 일부다 — 찍되 **빈 상태임을 표에 적는다** |
| 동적 경로에 항목이 0개 | 실패로 세고 이름을 댄다(시드 부족 신호다) |

# Failure Scenarios

1. **재굽기 전에 찍는다** → 상품 8개·아티스트 3명짜리 화면이 포트폴리오에 영구히 박힌다.
2. **로그인 화면을 그 페이지의 캡처로 저장한다** → 포트폴리오가 거짓이 된다. 200 과
   «로그인으로 튕김» 을 구별하라.
3. **102장을 전부 커밋한다** → 클론마다 15–50MB 가 따라다니고, 이미지 diff 는 리뷰가 안 된다.
4. **id 를 손으로 박는다** → 시드가 바뀌는 날 404 를 찍고, 그 실패는 **조용하다**(이미지는 생긴다).
5. **날짜로 낡음을 잰다** → 예약 트리거 함정. 경로 실재로 재라.
6. **인증 캡처가 재생성 가능하다고 적는다** → 기동 창에서만 된다. 그 약화를 적어라.
