# Goal

소유자 피드백(2026-09-15): 운영자 콘솔 카드의

```
로그인 후
도메인 헬스 대시보드 · …
↳ 데모 서버를 먼저 켜야 열립니다
↳ 위 미리보기 두 장이 이쪽 화면입니다 — 로그인 없이는 열리지 않습니다
```

가 *"너무 가독성이 떨어진다"*. 두 「↳」 문장은 **서로 다른 대상**을 말하는데 같은 자리에 쌓여 있었다.

1. 「데모 서버를 먼저 켜야」 — **로그인 후 항목 전체**에 걸리는 조건 ⇒ 그 항목의 **제목**에 붙는다.
2. 「위 미리보기 두 장이 이쪽 화면」 — **사진**에 대한 설명 ⇒ **사진 위**에 붙는다(그러면 「위 … 이쪽」 같은 지시어가 필요 없다).

소유자 선택 = **A안 + 사진 배지**:

- 제목: 「로그인 후 · 데모 서버 켠 뒤」(세 카드 공통) — `TASK-MONO-680` 의 버튼 「데모 서버 켜기」와 같은 동사.
- 운영자 콘솔 사진 왼쪽 위: 「🔒 로그인 후 화면」 배지. 스토어·팬의 사진은 로그인 없이 보이는 화면이라 붙이지 않는다.

# Edge Cases

- (z35) 는 카드 블록을 **줄 단위**로 센다. 표시가 `<dt>` 와 같은 줄에 있어야 한다 — 줄을 나누면 술어가 0 을 센다(의도된 엄격함: 표시가 다른 항목으로 옮겨가도 초록이던 옛 술어의 구멍을 막는다).
- (z35) 의 `data-shots` 카운트는 줄 기준이라 같은 줄의 `data-shots-note` 속성이 늘리지 않는다(실행으로 확인: 캐러셀 자리 1).
- 배지는 `::before` + `attr()` — `.shots` 가 이미 `position: relative` 이고 캐러셀 컨트롤은 `z-index` 없이 그려지므로 배지(`z-index: 2`)가 위에 온다. `pointer-events: none` 으로 사진 클릭을 막지 않는다.

# Failure Scenarios

- 🔴 **조건을 지우는 경우** — 「로그인 후」만 남으면 방문자가 로그인 화면까지 갔다가 막힌다(637). ⇒ 제목 안에 남기고 (z35) 가 그 자리를 요구한다.
- 🔴 **배지를 마크업 자식으로 넣는 경우** — `buildShots()` 가 상자에 트랙을 덧붙이고 (z35) 드라이버는 모르는 셀렉터에 죽는다. ⇒ 속성 + CSS 로만.
