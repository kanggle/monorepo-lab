# 이 티켓이 드러낸 것 (닫지 않고 기록만)

캡처를 눈으로 확인하다 발견했다: 세 화면 상단의 `DemoBackendNotice` 배너가
스토어·팬에서 *"데모 서버가 꺼져 있어 …데이터를 **불러올 수 없습니다**"* 라고 하는데,
**그 데이터를 그리고 있다.**

🔵 거짓은 아니다 — 백엔드는 실제로 꺼져 있고 화면에도 「샘플 데이터 (아직 발행 전)」이라
적혀 있다. 뜻은 «라이브 데이터가 아니라 샘플입니다» 다. 문제는 **문구가 에러처럼 읽힌다**는
것이고, 그 화면이 이제 포트폴리오 첫 화면의 캐러셀에 박힌다.

🔵 콘솔의 같은 배너는 *"로그인과 운영 데이터를 사용할 수 없습니다"* 로 **정확하다** — 그쪽은
실제로 못 쓴다. 즉 스토어·팬 문구만 `ADR-MONO-070`(공개 열람) 이전 표현으로 남은 드리프트다.

⇒ 별도 티켓으로 기안한다. 캡처는 `capture-shots.mjs` 한 번이면 다시 찍히므로, 문구를 고친
뒤 재생성하면 된다.
