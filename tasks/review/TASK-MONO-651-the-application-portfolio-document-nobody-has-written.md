# Edge Cases

- **데모가 꺼져 있을 때 링크를 누른다** — 정상이다. 론처가 그것을 설명한다. 문서는
  **켜는 데 걸리는 시간**만 미리 말하면 된다.
- **서비스 리포가 아직 추출되지 않았다** — 배지는 `github.com/kanggle/<service>` 를
  가리키는데 실제로 그 리포가 있는지는 **안 쟀다**. 🔴 링크를 걸기 전에 확인하라.
- **읽는 사람이 한국어를 못 읽는다** — 워크스루·티켓은 한국어다. 🔵 이 문서의 언어를
  소유자가 정해야 한다(AC-0 에 붙일 수 있는 두 번째 질문이다).
