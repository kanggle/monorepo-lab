# Edge Cases

- **~~재시작은 성공한다~~** — 🔴 **반증됐다(2026-08-17)**. 2차 사이클도 **16.5분 뒤 같은 방식으로
  굳었다**. 시드가 멱등이어도 소용없었다 ⇒ 시드는 **유일한** 원인이 아니다. 이 항목은 착수자가
  물려받으면 안 되는 틀린 전제라 취소선으로 남긴다. 판정은 여전히 **첫 부팅 + 시드**가 기본이지만,
  **재시작 경로도 같은 벽에 닿는다.**
- **공인 IP 가 매번 바뀐다**(EIP 없음). 실증 스크립트에 IP 를 박으면 다음 회차에 썩는다.
- **강제 stop 이 분류기에 차단된다** — `aws ec2 stop-instances --force` 는 Claude Code 자동모드에서
  막힌다. 데모 자신의 `/stop` 은 통과한다(면접관 경로라 오히려 적절).
- **수집기 자체가 부하다** — 1분 간격 `docker stats` 는 102개 컨테이너에서 가볍지 않다.
  `--no-stream` + 파일 append 로, 그리고 **수집기가 원인이 되지 않는지** 대조군을 둘 것.

# Failure Scenarios

- **측정 없이 인스턴스를 키운다** — 원인이 메모리가 아니면 돈만 쓰고 그대로 굳는다.
  그리고 "키웠더니 됐다" 는 관측은 다른 축의 변화(더 많은 vCPU, 다른 호스트)와 구분되지 않는다.
- **재시작 성공으로 닫는다** — 위 Edge Case 참조. 면접관은 항상 첫 부팅을 밟는다.
- **551 없이 닫는다** — 굳었는지 아닌지를 말할 수단이 없어 AC-1 이 판정 불가다.
- **세 번째 추측을 심는다** — `MONO-389`(잘린 웜업) · `MONO-397`(OOM kill) 이 이미 각자 후보를
  적었고 **둘 다 증명되지 않았다**. 증거 없이 셋째를 더하면 다음 사람은 검증된 적 없는 가설
  3개를 물려받는다. **판정 불가는 판정 불가로 적는다.**
