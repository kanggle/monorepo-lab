# Edge Cases

- 🔴 **복원한 볼륨을 어디서 돌릴 것인가.** EC2 를 새로 띄우면 그것도 비용이고, 로컬로
  가져오려면 100 GB 다. 🔵 **도커 볼륨 디렉터리만 뽑아내는 편이 싸다** — 필요한 것은
  iam MySQL 의 데이터 디렉터리 하나다.
- 🔴 그 MySQL 데이터 디렉터리는 **버전이 묶여 있다.** 복원한 데이터를 다른 메이저 버전으로
  띄우면 기동 자체가 실패하고, 그 실패는 **마이그레이션 판정처럼 보인다.** compose 의
  이미지 태그를 맞춰라.
- 🔴 스냅샷은 **교체 직전**의 상태다 — 그 인스턴스가 마지막으로 돈 시점 이후의 어떤 변경도
  담고 있지 않다. 「기존 이력」의 정확한 시점을 AC-0 ②로 확인하는 이유다.
- 🔵 이 판정이 참이든 거짓이든 **CI 는 안 바뀐다** — CI 는 구조적으로 신선 볼륨이다.
  결함이 나오면 필요한 것은 CI 수정이 아니라 **마이그레이션 수정**이다.

## AC-1 — 판정은 **행**으로 ✅

앞선 08-22 마이그레이션 파일은 **단 하나도 바뀌지 않았다**(`git log --since` = `V0033` 추가
1건뿐) ⇒ 볼륨의 08-22 집합 + `V0033` = **현재 집합과 동일**. 그래서 체크섬 검증이 구성상
성립하고 재현이 충실하다. 데모가 쓰는 `e2e` 프로파일 그대로 **`migration` + `migration-dev`,
`outOfOrder=true`** 로 Flyway 를 돌렸다(그 프로파일이 아니면 적용된 `R__` 3건이 *missing* 으로
검증에 걸린다).

```
Successfully validated 36 migrations
Current version of schema `auth_db`: 0032
Migrating schema `auth_db` to version "0033 - add fan vercel domain redirect uri"
Successfully applied 1 migration ... now at version v0033
```

**판정 술어는 문자열 부분일치가 아니라 JSON 배열 원소 동등성으로 했다:**

| 술어 | 기존 볼륨 |
|---|---|
| `JSON_CONTAINS(redirect_uris, JSON_QUOTE('https://fan.hubwang.com/api/auth/callback/iam'))` | **1** ✅ |
| `JSON_VALID(redirect_uris)` | **1** ✅ (문자열 `REPLACE` 가 JSON 을 안 깼다) |
| `post-logout-redirect-uris[1]` 에 `https://fan.hubwang.com/` | **1** ✅ |

🔵 `LIKE '%fan.hubwang.com%'` 로 안 잰 이유: 그 술어는 **주석에 그 문자열이 있어도 참**이고,
배열이 깨진 채 텍스트만 들어 있어도 참이다. 원소 동등성만이 *"OAuth 정확 일치가 성립한다"* 를 잰다.
