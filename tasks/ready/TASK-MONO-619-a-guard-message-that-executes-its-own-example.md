# Acceptance Criteria

## AC-0 — 착수 시 **다시 센다** (verify-then-act)

1. 위 9건이 **여전히 9건인지** 다시 스캔한다. 🔴 그 사이 누가 메시지를 고치면 줄 번호가
   밀린다 — 줄 번호가 아니라 **내용**으로 찾아라.
2. 🔴 **모집단을 상속하지 마라** — `infra/demo/*.sh` · `scripts/*.sh` 밖에도 같은 모양이
   있는지 본다(`.github/workflows/*.yml` 안의 인라인 `run:` 도 셸이다).
3. 🔵 **오늘 PATH 에 있는 토큰이 있는지** 확인한다. 있으면 그 줄이 **우선순위 1**이다.

## AC-1 — 9건을 고친다. **문구는 바꾸지 않는다**

백틱을 `\`` 로 이스케이프한다. 🔴 백틱을 **지우거나** 다른 기호로 바꾸지 마라 —
이 저장소의 메시지는 코드 조각을 백틱으로 감싸는 관례를 따르고, 그것이 처방의 가독성이다.

## AC-2 — 🔴🔴 **재발 방지 가드**. 술어는 **인용 문맥**을 본다

- 무는 조건: **큰따옴표 문자열 안**의 미이스케이프 백틱.
- 🔴 **작은따옴표 안은 안 문다** — 위 거짓 양성이 그 요구사항이다.
- 🔴 **주석은 안 문다** — 이 저장소의 헤더 주석은 백틱을 정상적으로 쓴다.
- 🔴 **가드 자신의 설명 문구에 걸리지 않게** 하라. `TASK-MONO-604` 가 밟은 함정이다
  (판별자가 자기 문서에 매치한다). [[feedback_a_discriminator_can_match_its_own_documentation]]
- 🔵 자리는 **정적 구간**이다(파일을 읽을 뿐 데모가 필요 없다).
  🔴 `verify --live` 의 **(f) 뒤는 금지** — 도달하지 않는다(`TASK-MONO-617` 이 실측).

## AC-3 — bite. **주입을 먼저 단언한다**

- **주입**: 임의의 메시지 줄에 미이스케이프 백틱을 하나 넣는다 → 가드가 **rc≠0**,
  메시지가 **파일·줄·실행될 토큰**을 이름으로 댄다.
- **대조군 ①**: 주입 전 **rc=0**.
- **대조군 ②**: 🔵 **작은따옴표 안의 백틱**을 넣는다 → **rc=0 이어야 한다**(거짓 양성 금지).
- **대조군 ③**: 🔵 **주석 안의 백틱** → **rc=0 이어야 한다**.
- 🔴 셋을 다 넣어야 한다. ①만 보면 「늘 무는 가드」와 구별되지 않고, ②③이 없으면
  **멀쩡한 코드를 고발하는 가드**가 된다 — 그런 가드는 꺼진다.

## AC-4 — 🔴 **모집단 하한**

스캔한 파일 수가 **0이면 FAIL** 이다. glob 이 안 맞아 0개를 스캔하고 「위반 0건」으로
통과하는 것이 이 부류 가드의 표준 고장이다. [[env_empty_detector_output_is_not_absence]]

# Edge Cases

- 🔴 **`$'\n'"…"` 이어붙임 줄** — 이 저장소의 `fail` 호출은 여러 줄로 이어진다. 그 줄들은
  `fail` 로 시작하지 않으므로 「호출 줄」만 보는 술어는 **9건 중 8건을 놓친다**(실측: 9건 중
  8건이 이 모양이다).
- 🔴 한 줄에 백틱이 **홀수 개**면 짝이 안 맞아 다음 줄까지 먹는다 — 그 경우 증상이
  「문구 소실」이 아니라 **구문 오류**이거나 더 넓은 실행이다.
- 🔵 `bash -n` 은 이 결함을 **못 잡는다** — 문법적으로 완전히 정상이기 때문이다.
  그래서 별도 가드가 필요하다.
- 🔴 이스케이프한 뒤 **메시지를 실제로 출력시켜 눈으로 확인**하라. `bash -n` 통과는 증거가
  아니다(위 줄과 같은 이유).

| 상황 | 잘못된 처리 | 옳은 처리 |
|---|---|---|
| 「지금 PATH 에 없으니 무해」 | 안 고치고 닫는다 | 🔴 617 의 `docker` 는 **있었고 실행됐다**. 내용은 다음 사람이 바꾼다 |
| 백틱을 **지워서** 해결 | 처방의 코드 조각이 평문이 되어 읽기 어려워진다 | 🔴 **이스케이프**하라 |
| 작은따옴표 안까지 고발 | 멀쩡한 코드가 빨개지고 가드가 꺼진다 | 🔴 술어가 **인용 문맥**을 본다 (대조군 ②) |
| 호출 줄만 스캔 | 🔴 **9건 중 8건을 놓친다**(`$'\n'"…"` 이어붙임) | 이어붙임 줄도 모집단에 넣어라 |
| 스캔 0파일로 통과 | 「위반 없음」이 아니라 **안 봤다** | 🔴 **파일 수 하한** |
| 위반 수에 하한을 건다 | 다 고치면 성공이 고장난다 | 🔵 이 모집단은 **비어 가는 것이 목표**다 |
