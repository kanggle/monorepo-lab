# Edge Cases

- 🔴 **비밀번호·토큰·소셜 키를 출력하지 않는다** — 데모 비밀번호는 `infra/demo/seed/lib.sh` 기본값을 **변수에만** 넣고 길이만 확인(2026-10-05 22차 창에서 «가림» 출력이 빗나가 한 번 찍혔다). 콘솔 `/login` 화면 본문은 비밀번호를 보여 주므로 덤프하지 않는다.
- 🔴 날짜는 `date -u +%F` 를 **그 자리에서 실행**해 적는다(시스템 알림의 날짜는 로컬 KST).
- 쓰기 흐름은 데모 데이터를 바꾼다 — 다음 재굽기 apply 가 신선 볼륨으로 되돌리므로 허용. 단 시드 계정의 비밀번호·권한은 바꾸지 않는다.
- 테넌트 전환은 **왕복**(같은 값 재선택은 no-op). 이커머스 화면은 `ecommerce`, scm·erp·finance 는 `demo-corp`.
- 데모는 20분 무신호면 꺼진다 — 5분마다 `POST /heartbeat`.
- 305 처럼 **데모를 정지하는 판정은 맨 마지막**.

# Failure Scenarios

1. **페이지가 열린 것을 PASS 로 센다** — 648 촬영과 같은 판정이 되어 쓰기 결함을 못 본다(AC-1 이 막는다).
2. **FAIL 을 이 티켓 안에서 고친다** — 측정과 수정이 섞여 창 시간을 다 쓴다. 기안만 한다.
3. **CI Nightly 초록을 근거로 PASS 를 적는다** — 다른 환경이다.
4. **소셜 가입을 소유자 계정이 아닌 가짜로 시도** — 실제 제공자는 실계정만 통과한다. 소유자 참여가 필요하다(창 계획에 적는다).
