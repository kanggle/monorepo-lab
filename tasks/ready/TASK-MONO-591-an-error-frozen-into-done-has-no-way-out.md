# 🔴 선행 질문 — **이게 한 파일인가, 아니면 여러 개인가**

`TASK-MONO-589` 는 모집단을 **1로 가정하고 시작해 9를 발견했다.** 같은 실수를 반복하지 않는다.

`done/` 안에는 «지금 진행 중» 을 말하는 자기 선언이 **구조적으로 낡을 수밖에 없다** —
`⏳`, `🟡 BLOCKED`, `대기`, `미정`, `AC-N 남음`, `PROPOSED` 같은 문구가 닫힌 파일에 남아
있으면 전부 같은 클래스다. **AC-0 이 그 수를 센다. 처방은 그 숫자를 보고 정한다.**

🔵 **한 건이면 «그 한 건을 어떻게 고치나» 이고, 수십 건이면 «`done/` 헤더에 진행 상태를
쓰는 관행 자체» 가 문제다.** 두 경우의 답이 다르다.

# Acceptance Criteria

## AC-0 — **모집단을 센다. 여기서 처방이 갈린다**

`tasks/done/` 과 `projects/*/tasks/done/` 전수에서, **닫힌 파일에 남은 진행-상태 선언**을
찾아 **개수와 목록**을 티켓에 적는다.

- 후보 술어(출발점일 뿐 — 실제 문구를 보고 넓혀라): `대기` · `⏳` · `🟡 BLOCKED` ·
  `DO NOT START` · `미정` · `PROPOSED` · `남음` · `Status` 필드와 본문 헤더의 불일치.
- 🔴 **선언 파일 grep 만으로 판정하지 마라** — 문구가 있다고 다 낡은 것이 아니다.
  «그때의 관측 기록» 과 «지금 거짓인 상태 선언» 은 다르고, **후자만 모집단이다.**
  최소 **상위 몇 건은 열어서 읽어라.** [[env_a_resolver_that_cannot_answer_returns_a_plausible_one]]
- 🔵 **양성 대조군**: `done/TASK-MONO-575:13` 이 반드시 잡혀야 한다. 안 잡히면 술어가 틀렸다.
  [[feedback_assert_the_injection_before_reading_the_bite]]

## AC-1 — **정하고 근거를 적는다**

A/B/C/D(또는 조합)를 고른다. 🔴 **AC-0 의 숫자를 인용해서** 정한다 — 숫자 없이 고른 처방은
왜 그것인지 나중에 알 수 없다.

🔴 **D 를 고르는 것도 유효한 결론이다.** 그 경우 «그러면 ①의 파일은 계속 거짓을 말한다» 를
명시적으로 수용한다고 적는다 — 조용히 넘어가지 마라.

## AC-2 — 🔴 **`done/` 의 임의 편집은 여전히 막혀야 한다**

무엇을 고르든, **음성 대조군**이 초록이어야 한다:

| 케이스 | 기대 |
|---|---|
| `done/` 파일 본문 임의 편집 | **block** (`TASK-MONO-402` 가 지킨 것) |
| `done/` Status 라이프사이클 이동 | **allow** (마감 chore 가 여기 걸리면 전부 깨진다) |
| `review/` 본문 편집 | **block** |
| (A 를 골랐다면) 규정된 정정 블록 | **allow** |

🔴 **정정 예외를 만들면서 임의 편집까지 열면, 이 티켓이 `TASK-MONO-402` 를 되돌리는 것이
된다.** 위 네 칸을 전부 픽스처에 넣어라. [[project_guard_design_requirements]]

## AC-3 — 고쳤다면 ①을 실제로 고친다

선택한 방법으로 `done/TASK-MONO-575` 의 헤더를 정정하고, **정정 후 파일을 다시 읽어**
헤더와 본문·`Status` 가 일치하는지 확인한다. (D 를 골랐다면 이 AC 는 «수용을 기록» 으로 대체.)

## AC-4 — 가드는 **어디서 도는가**

훅 픽스처를 건드리면 `ci.yml` 의 `Hook fixtures` 잡이 그것을 본다
(`if: needs.changes.outputs.hooks == 'true'`, 필터는 `.claude/hooks/**` ·
`.claude/settings.json` · `platform/hardstop-rules.md` — 마지막 항목은 `TASK-MONO-589` 가
추가했다). 새 가드를 **다른 곳**에 두면 그 러너를 직접 확인하고 적는다.
🔴 러너 없는 가드는 썩는다. [[feedback_two_correct_exclusions_compose_into_a_hole]]
