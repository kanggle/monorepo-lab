바뀐 것**이다.

## 🔴🔴 그러니 뒤집을 때 **한 축을 잃지 마라**

(z14) 를 "스토어 행은 예외" 로 느슨하게 만드는 것은 틀린 뒤집기다. 그러면 **데모 호스트
행에서 실수로 정적 주소를 쓰는 것**도 통과한다. 새 축은 이것이다:

> **각 화면이 어디서 서빙되는가** — 그리고 **그 출처에 맞는 판정을 받는가.**

| 서빙 출처 | 링크 정책 | 주소 |
|---|---|---|
| **Vercel** | **항상 활성** (데모 상태와 무관) | 정적 · `demoHost()` 를 **안 탄다** |
| **데모 호스트** | 기존 네 칸 그대로 | `demoHost()` 파생 · sslip 직기입 금지 |

🔵 즉 칸이 줄지 않는다. **행마다 어느 칸을 받는지가 마크업에서 선언되고**, 가드는
그 선언을 읽어 **두 정책 모두** 실행 대조한다. 선언이 없거나 모르는 값이면 **판정 불가로
실패**시킨다(모르는 것은 통과가 아니다).

## 산문 불변식이 하나 남는다

## 형제 소비자가 하나 더 있다 — `demo-up.sh`

🔴 **Vercel 행은 데모 호스트에 존재하지 않는다.** 그대로 두면 부팅 판정이 영원히 열리지

# Acceptance Criteria

## AC-0 — 전제 재측정 (**착수 전**)

1. web-store 의 Vercel **프로덕션 URL 을 실제로 찔러** 2xx 를 확인한다.
   🔴 대시보드에 프로젝트가 보이는 것은 증거가 아니다 — **응답이 증거다.**
2. 그 URL 이 **데모가 꺼진 상태에서도** 뜨는지 확인한다. 이 티켓의 전체가 그 명제 위에 선다.
   꺼진 상태에서 500 이면 **뒤집지 말고 멈춘다.**
3. `demo-up.sh` 의 `SURFACE_FLOOR` 와 (z14) 의 `z14_floor` **현재 값**을 읽는다.

## AC-1 — 마크업이 **서빙 출처를 선언**한다

각 `data-surface` 행이 어디서 서빙되는지 선언한다(속성 이름은 구현 판단).
🔴 **기본값을 두지 마라** — 선언이 없는 행은 가드가 **판정 불가로 실패**시킨다.
빠뜨린 행이 조용히 한쪽 정책을 받는 것이 이 티켓이 막아야 할 실패다.

## AC-2 — `(z14)` 가 **두 정책 모두**를 실행 대조한다

| | Vercel 행 | 데모 호스트 행 |
|---|---|---|
| `up` | 활성 | 활성 · href 가 `demoHost()` 파생 |
| `down`/`unknown` | **활성** (bite ← 뒤집힌 칸) | **비활성 · href 없음** |
| `partial` | **활성** | 비활성 |
| `health_stale` | **활성** | 비활성 |

- 🔴 **sslip 직기입 금지는 유지**하되 **데모 호스트 행에만** 건다.
- 🔴 **모르는 출처 값 → 실패.** 대조군으로 확인한다.
- 🔴 **양쪽 모집단이 각각 ≥1** 임을 단언한다. 한쪽이 0이면 그 정책은 **안 재고도 초록**이다.

## AC-3 — `demo-up.sh` 가 **찌를 것만 찌른다**

- 부팅 판정은 **데모 호스트 행만** 찌른다.
- `SURFACE_FLOOR` 를 재계산하고 **provenance 와 함께** 적는다.
- 🔴 추출 0건은 **판정 불가**(현재 동작 유지) — 초록이 되면 안 된다.

## AC-4 — 링크 전환 + 산문 정정

- 🛒 행이 Vercel URL 을 가리킨다.
- 191번 근처 *"모든 링크는 반드시 demoHost() 를 통과한다"* 를 **새 사실로** 고친다.
- 🔵 **왜 예외가 생겼는지**를 적는다 — 값만 고치면 다음 사람이 원복한다.

## AC-5 — 검증

- `(z14)` 를 실제로 실행해 통과 (Docker 불요 — 이 칸은 node 만 쓴다)
- 🔴 **bite 3종**: ⑴ Vercel 행을 `down` 에서 비활성으로 되돌리면 문다
  ⑵ 데모 호스트 행에 정적 주소를 넣으면 문다 ⑶ 출처 선언을 지우면 문다
- `bash -n` · `demo-up.sh` 의 표면 추출을 **드라이런으로** 확인

# Edge Cases

- 🔴 **마크업의 소비자가 둘**((z14) · `demo-up.sh`)이고 둘 다 하한을 갖는다.
  한쪽만 고치면 다른 쪽이 **부팅을 영원히 기다린다.**
- (z14) 는 `<a ... data-surface>` 개수와 파싱된 개수를 **대조**한다. 속성을 하나 추가하면
  그 정규식이 행을 통째로 흘릴 수 있다 — 흘리면 그 행은 **판정에서 빠지고 가드는 초록**이다.
- 🔴 **`DEMO_SURFACE_SRC`** 로 다른 파일을 물릴 수 있다((z15)가 그렇게 쓴다). 하한을
  올리면 그 임시 트리도 새 하한을 만족해야 한다.
- Vercel URL 을 `config.js`(런타임 주입)에 둘지 마크업에 둘지는 구현 판단이나,
  🔴 **`config.js` 는 terraform 이 더는 렌더하지 않는다**(`TASK-MONO-579` 가 S3 사본을 폐기).
  지금 그 값은 Vercel **환경변수**이고 빌드 타임에 들어간다.
