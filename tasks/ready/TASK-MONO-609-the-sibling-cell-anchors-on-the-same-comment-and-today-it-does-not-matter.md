# 기전 — 같은 결함, 다른 소비자

`infra/demo/verify-demo-wrapper.sh` 의 `(z2)` 는 정적 구간의 경계를 이렇게 잡는다:

```bash
z2_live="$(grep -n 'if \[ "\$LIVE" -eq 0 \]' "$z2_self" | head -1 | cut -d: -f1)"
```

열을 안 본다. 이 파일에서 그 문자열의 등장은 셋이다:

| 줄 | 정체 |
|---|---|
| **2699** | `(z16)` 의 서술 주석 (*"(z15) 를 `if [ "$LIVE" -eq 0 ]` 블록 **안**에 넣었다"*) ← `head -1` 이 고른다 |
| 2711 | `(z16)` 의 또 다른 주석 |
| **2914** | 진짜 게이트 (열 0) |

⇒ `(z2)` 의 「정적 구간」은 파일 처음 ~ **2699** 이고, **진짜 경계보다 215줄 짧다.**

## 🔵 그런데 오늘은 답이 같다 — 그래서 아무도 안 본다 (2026-09-01 실측)

| 경계 | 추출된 `command -v` 도구 |
|---|---|
| `(z2)` 가 쓰는 2699 | `node` |
| 진짜 게이트 2914 | `node` |

**그 215줄에 `command -v` 선언이 0건**이라 두 집합이 같다. ⇒ **실재하지만 잠복**이다.
🔴 «지금 아프지 않다» 가 «앞으로도 안 아프다» 가 아니다.

## 🔴 답이 달라지는 순간의 증상

누가 2699–2914 사이(= `(z13)`~`(z16)` 구역)에 `command -v <tool>` 를 하나 추가하면
`(z2)` 는 그것을 **조용히 놓친다**. 그러면 packer 1단계가 그 도구를 안 깔고,
빌드는 **이미지를 다 구운 뒤 20분째 7단계에서** 죽는다 — 이 파일이 주석으로 기록한
**2026-08-17 의 그 실패**다. `(z2)` 가 존재하는 이유가 정확히 그 사건이다.

# Scope

**In:**

- `(z2)` 의 `z2_live` 앵커를 열 0 고정(`^if \[ "\$LIVE" -eq 0 \]; then$`)으로.

- bite — 경계 **뒤쪽**(2699~2914 사이)에 `command -v` 를 주입하면 `(z2)` 가 그것을 보게 된다.

**Out:**

- `(z16)` — `608` 이 이미 고쳤다.
- packer 파일 자체.

# Acceptance Criteria

## AC-0 — verify-then-act

착수 시점에 **두 경계가 여전히 다른지**, 그리고 **두 도구 집합이 여전히 같은지** 다시 재라.

- 경계가 같아졌으면 누가 고쳤는지부터 찾고 **STOP**.
- 🔴 **집합이 이미 달라졌으면** 그건 잠복이 끝났다는 뜻이다 — 우선순위가 올라간다.
  그때는 `(z2)` 가 **지금 무엇을 놓치고 있는지**부터 적어라.

## AC-1 — 주입으로 물기를 증명한다

- 🔴 **주입을 먼저 단언하라** — 경계 사이(2699~2914)에 `command -v <없는도구>` 를 넣고,
  그 줄이 **진짜 게이트 «앞»이고 옛 경계 «뒤»** 인지 줄 번호로 확인한다.
- 고치기 **전** 판본: 그 도구가 `z2_seen` 에 **안 나타난다**(= 놓친다).
- 고친 **후** 판본: 나타나고, packer 에 없으므로 **FAIL** 한다.
- 🔵 **두 방향 다** — 옛 경계 «앞»에 넣은 도구는 양쪽 다 잡아야 한다(음성 대조군).

## AC-2 — 0건 하한은 이미 있다. **약해지지 않았는지** 확인만 한다

`(z2)` 에는 이미 *"추출 0건을 '의존 없음' 으로 보고하지 않습니다"* 하한이 있다.
🔴 앵커를 고치면서 그것이 **여전히 도달 가능한지** 확인하라 —
경계가 파일 뒤로 밀리면 0건이 나올 확률은 오히려 줄지만, **하한을 지웠는지**는 별개 문제다.

## AC-3 — 🔴 **복제하지 마라**

`(z16)` 과 `(z2)` 가 이제 같은 앵커를 쓴다. **같은 사실이 두 곳에 생기면 한쪽만 고쳐진다.**
공용 헬퍼(예: `live_gate_line <file>`)로 뽑을지, 아니면 두 곳에 두되 **서로를 이름으로 지목하는
주석**을 달지 결정하고, 그 결정을 적어라. [[feedback_one_fact_in_two_sections_only_one_gets_fixed]]

## AC-4 — 안 고치는 것을 적는다

- `(z2)` 가 `if [ -f "$z2_pkr" ] && [ -f "$z2_self" ]; then` 안에 통째로 들어 있고
  **else 가 없다** — 파일이 옮겨지면 이 칸은 **조용히 사라진다**. 그 축은 이 티켓이 안 본다.
