# Goal

포트폴리오 첫 화면(`hubwang.com` 론처)의 카드 세 장을 방문자 기준으로 다시 쓴다.

1. **로그인 없이 되는 기능**과 **로그인해야 되는 기능**을 카드마다 간략히 명시한다.
2. 이미지 자리를 **캐러셀**로 바꾼다(주요 화면 여러 장). 🔴 이 티켓은 **캐러셀 골격과 폴백**
   까지다 — 실제 캡처 이미지를 채우는 것은 `TASK-MONO-639` 다.
3. `둘러보기 →` 링크를 없애고 **제목**(`운영자 콘솔` · `이커머스 스토어` · `팬 플랫폼`)에서
   링크가 걸리게 한다.
4. 클릭되는 곳은 호버 시 **손가락 커서**가 뜬다(지금 `<button>` 은 화살표다).

# Acceptance Criteria

## AC-0 — 착수 전 실측 (verify-then-act)

- [ ] 서빙 중인 `build-info.json` 의 commit 과 `index_md5` 를 적고, 그 판을 보고 고친다.
- [ ] `(z14)` 를 **먼저 한 번 돌려** 현재 `data-surface` 행이 몇 개로 추출되는지 적는다
      (`z14_loose` ↔ `z14_got`). 🔴 이 값이 변경 전후로 **같아야** 한다 — 그것이 이 티켓이
      가드를 안 깨뜨렸다는 증거다.

## AC-1 — 로그인 전/후를 카드가 말한다

- [ ] 카드마다 **로그인 없이 되는 것**과 **로그인해야 되는 것**을 각각 한 줄로 명시한다.
- [ ] 🔴🔴 **«로그인하면 된다» 로 뭉치지 마라.** 로그인 후 기능은 로그인만으로 되는 것이
      아니라 **데모 백엔드가 기동돼 있어야** 한다. 즉 상태가 셋이다:
      ① 지금 됨(Vercel 공개 열람) ② 실시간 기능 기동 + 로그인 필요 ③ 기동 안 됨.
      ②를 «로그인하세요» 라고만 쓰면 방문자가 로그인 화면에 가서 막히고, 그것은
      `TASK-MONO-636` 이 방금 고친 «이유를 말하지 않는 화면» 과 같은 부류다.
- [ ] 적은 문구가 **사실인지 확인한다** — 세 화면을 실제로 열어 로그인 없이 되는 것을 세고,
      그 목록으로 쓴다. 🔴 스펙이나 기억이 아니라 **화면**에서 센다.

## AC-2 — 이미지 자리가 캐러셀이 된다

- [ ] 카드 이미지 영역이 **여러 장을 넘길 수 있는 캐러셀**이 된다(좌우 이동 + 현재 위치 표시).
- [ ] 🔴 **이미지 0장에서 깨지지 않는다.** `thumbnails/` 가 없는 지금 상태에서도 카드가
      정상으로 서고 이모지 폴백이 뜬다(회귀 금지 — 이것이 오늘의 실제 상태다).
- [ ] 1장일 때 이동 컨트롤이 **뜨지 않는다**(넘길 곳이 없는데 화살표가 보이면 고장으로 읽힌다).
- [ ] 이미지 하나가 404 여도 **그 칸만** 폴백이고 나머지 장과 캐러셀은 산다.
- [ ] 🔴 자동 재생을 넣지 않는다 — 스크린리더·모션 민감 사용자에게 해롭고, 이 페이지의
      목적은 «움직이는 것» 이 아니라 «무엇인지 보이는 것» 이다.

## AC-3 — 제목이 링크가 되고 「둘러보기 →」가 사라진다

- [ ] `둘러보기 →` 앵커를 없애고, **제목**이 그 자리의 링크가 된다.
- [ ] 🔴🔴 `data-surface`·`data-domain`·`data-served`·`data-url` 은 **제목 앵커로 옮겨간다.**
      (z14) 의 추출식은 `<a [^>]*data-surface` 를 **한 줄에서** 읽으므로 여는 태그와 그
      속성들이 **같은 줄**에 있어야 한다. 줄을 나누면 그 행이 통째로 안 잡히고, 가드는
      «링크 2개» 를 정상으로 보고한다.
- [ ] `a.thumb-link` 의 **하드코딩된 `href` 를 없앤다** — 같은 곳으로 가는 링크가 둘인데
      하나만 가드가 본다. 캐러셀도 링크가 되어야 한다면 주소를 `data-url` 에서 가져온다
      (마크업에 두 벌로 적지 않는다).
- [ ] 비활성 상태(`renderSurfaces()` 가 `off` 를 켜고 `href` 를 지우는 경로)가 **제목
      앵커에서도** 그대로 동작한다 — CSS 선택자(`a.open.off`)가 클래스 이름 변경을 따라간다.
- [ ] ADR-MONO-071 § D7 유지: 제목·이미지는 **정적 Vercel 주소로만** 가고 기동을 겸하지
      않는다(겸하면 요금이 걸린 부작용이다).

## AC-4 — 클릭되는 곳은 손가락 커서

- [ ] 활성 기동 버튼(`.bstart.on`)·캐러셀 컨트롤·`<summary>` 등 **클릭되는 모든 것**이
      호버 시 `cursor: pointer` 다.
- [ ] 🔴 **비활성은 그대로 둔다.** 잠긴 버튼과 `a.open.off` 는 손가락이 아니어야 한다 —
      손가락은 «누를 수 있다» 는 신호이고, 못 누르는 곳에 주면 거짓말이다.

## AC-5 — 가드

- [ ] `(z14)` 가 변경 후에도 **같은 개수**의 행을 뽑는다(`z14_loose == z14_got`, AC-0 의 값과 일치).
- [ ] 이 티켓의 축을 무는 칸을 **어디에 둘지 정하고 근거를 적는다**. 최소한 다음을 **실행
      또는 추출로** 재라(문자열 grep 만으로 짜면 자기 문서에 걸린다):
      · `둘러보기` 앵커가 사라졌는가 · 제목 앵커가 `data-surface` 를 드는가
      · 카드마다 링크가 **한 개**인가(둘이면 하나만 가드가 본다)
      · 캐러셀이 0장·1장·N장에서 각각 옳은가
- [ ] **bite**: 위 각 축마다 결함을 되살렸을 때 가드가 빨개지는지 확인한다.

# Edge Cases

| 상황 | 기대 |
|---|---|
| `thumbnails/` 없음(오늘) | 카드 정상 · 이모지 폴백 · 캐러셀 컨트롤 없음 |
| 이미지 1장 | 이동 컨트롤 없음 |
| 이미지 N장 중 하나가 404 | 그 칸만 폴백, 캐러셀은 계속 동작 |
| `config.js` 부재 | 둘러보기(제목 링크)는 **살아 있다** — 기동만 잠긴다(회귀 금지) |
| 도메인이 비활성 | 제목 링크가 `off` 가 되고 `href` 가 사라진다(클릭도 새 탭도 없음) |
| 키보드 탐색 | 제목 링크와 캐러셀 컨트롤이 Tab 으로 닿고 Enter 로 동작 |

# Failure Scenarios

1. **`data-surface` 를 제목 앵커로 옮기면서 속성을 여러 줄로 쓴다** → (z14) 가 그 행을
   통째로 흘리고, 그 상태에서 링크가 죽어도 가드는 초록이다.
2. **`a.thumb-link` 의 하드코딩 `href` 를 남겨 둔다** → 같은 곳으로 가는 링크가 둘이고
   가드는 하나만 본다. 비활성 처리도 한쪽에만 걸려 «흐린데 클릭되는» 링크가 된다.
3. **로그인 후 기능을 «로그인하세요» 로만 쓴다** → 방문자가 로그인 화면에서 막힌다.
   백엔드 기동이 전제라는 사실이 화면에서 사라진다.
4. **캐러셀을 이미지가 있다고 가정하고 짠다** → `thumbnails/` 가 없는 오늘 카드가 깨진다.
