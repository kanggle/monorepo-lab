### 🔴🔴 그리고 이것이 **기동 창 전체의 선행**으로 올라간다

| 항목 | `582`(Vercel 프로젝트) 없이 기동하면 |
|---|---|
| ① `TASK-BE-580` AC-4 | ✅ 잴 수 있다 |
| ② `TASK-BE-581` AC-4 | ✅ 잴 수 있다 |
| **④** `TASK-MONO-580` 라이브 — *"Vercel 스토어가 데모 백엔드에 닿는가"* | 🔴 **잴 수 없다** — 찌를 Vercel 스토어가 없다 |
| **⑤** 데모 호스트 `web-store` 컨테이너 제거 | 🔴 **하면 안 된다** — 위 술어 |
| ⑥ `TASK-BE-582` 기존 볼륨 판정 | ✅ 잴 수 있다 |

⇒ **`582` 의 소유자 클릭 없이 기동하면 여섯 중 ①②⑥ 셋만 정리되고, ④⑤ 때문에 두 번째 기동이
필요해진다.** 🔴 그것은 이 티켓의 제목(*"기동 **한 번**"*)과 § 묶는 항목의 *"나눠 쓰지 마라"* 가
금지하는 바로 그것이고, 예산은 **잔여 104분 / 부팅 1회 ≈ 11분**이다.

🔵 **그러므로 실행 순서가 정해진다**:

```
TASK-MONO-582 소유자 클릭 (Vercel 프로젝트 생성)
   → 582 AC-4 첫 배포 로그 반영 → 582 close
   → [여기서] 재굽기 + 기동 1회 = ①②④⑤⑥ 전부
```

🔴 **AC-0 에 이 칸을 추가한다** — 착수 전에 `git ls-files '*vercel.json'` 이 아니라
**커밋 상태 행에 `Vercel – ` 컨텍스트가 셋인지**로 확인하라(파일은 이미 셋이지만
프로젝트가 없으면 Vercel 이 그 파일을 읽지 않으므로 **파일 개수는 답이 아니다**).
