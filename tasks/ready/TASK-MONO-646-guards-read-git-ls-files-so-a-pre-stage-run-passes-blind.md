# Goal

이 저장소의 `scripts/` 가드 **53개 중 20개**가 모집단을 `git ls-files` 로 만든다. `git ls-files`
는 **인덱스(스테이징 영역)** 를 읽으므로, 아직 `git add` 되지 않은 새 파일은 **존재하지 않는
것과 같다.** 그래서 로컬에서 가드를 스테이지 전에 돌리면 — 결함이 있어도 — **초록이 나온다.**

🔴 이것은 「가드가 틀렸다」가 아니라 **「가드를 돌린 시점이 가드의 모집단을 바꿨다」** 이고,
실패 모양이 **성공과 구별되지 않는다**: 새 파일이 0건이면 검사 대상도 0건이라 가드는 조용히
`exit 0` 한다. 「0건 ≠ 없음」의 정확한 사례다.

이 규칙이 **저장소 어디에도 적혀 있지 않다.** `CLAUDE.md` § Task Rules 에는 바로 옆 축인
*`git mv review/ → done/` re-stage check* 가 이미 있는데 — 그 규칙도 「스테이징된 blob 이
진짜인가」를 묻는 같은 부류다 — **가드 실행 시점** 축만 비어 있다. 그 결과 이 함정은
에이전트 메모리에만 남았고 **3회 재발**했다.

이 티켓이 참으로 만들 것: **가드를 로컬에서 돌리는 사람은, 돌리기 전에 스테이지해야 한다는
것을 저장소에서 읽을 수 있다.**

## 🟢 이미 실측됐다 — 이 티켓 자신을 재료로 (2026-09-09 UTC, worktree `mono-646`)

`scripts/check-index-queue-drift.sh` 하나에 **같은 트리·같은 파일**로 세 번 물었다. 바뀐 변수는
**인덱스에 무엇이 들어 있나** 하나뿐이다.

| # | 상태 | rc | 가드가 한 말 | 진실 |
|---|---|---:|---|---|
| A | 파일 미추적 + INDEX 행 **없음** | **0** | *"listing and directory agree in both directions"* | 🔴 **거짓 초록** — `tasks/ready/` 에 미등재 파일이 **1개** 있다(`ls`=1, `git ls-files`=**0**) |
| B | 파일 미추적 + INDEX 행 **있음** | **1** | *"no file with that ID exists **anywhere under `tasks/`**"* | 🔴 **거짓 빨강** — 파일은 디스크에 있다 |
| C | 둘 다 `git add` 후 | **0** | 동일 문구 | ✅ 참인 초록 |

🔴🔴 **A 가 위험한 쪽이다.** 결함이 있는데 가드가 *"양방향으로 일치"* 라고 **적극적으로**
말한다 — 두 모집단이 **둘 다 비어서** 일치한 것이고, 그 문장은 「검사했고 괜찮다」와
글자 그대로 같다. 기록된 재발(`TASK-MONO-572`)이 정확히 A 였다: INDEX 행이 잘못된 앵커로
산문 절에 들어갔고, 파일도 미추적이라 **결함 둘이 서로를 상쇄해** 초록이 났다.

🔵 B 는 덜 위험하다(빨강은 사람을 멈춰 세운다). 하지만 **사유가 틀렸다** — *"anywhere under
`tasks/`"* 라는 단정은 디스크가 아니라 인덱스를 근거로 한 것이고, 이 문구를 믿으면 있는
파일을 다시 만든다.

## Out of Scope

  가드의 의도). 문제는 스크립트가 아니라 **실행 시점의 규율**이고, 그건 문서의 몫이다.

# Edge Cases

- **`git add -A` 를 이미 습관적으로 하는 세션** — 규칙은 무해하게 참이다. 비용 0.
- **worktree** — `git ls-files` 는 그 worktree 의 인덱스를 읽는다. 파킹 체크아웃에서 돌리면
  **다른 트리를 잰다**(이 저장소의 「하네스가 어느 트리를 재는지 먼저 확정」과 같은 축).
- **삭제된 파일** — 반대 방향. 스테이지 전에는 `git ls-files` 가 **아직 있다고** 답하므로,
  삭제를 검증하는 가드는 스테이지 전에 **거짓 빨강**을 낸다. 규칙은 양방향이다.
- **`.gitignore` 에 걸린 파일** — 스테이지해도 안 보인다. 🔴 `TASK-MONO-640` 이 정확히 이
  부류였다(`bin/` 이 필수 생성기를 삼켰다) — 이 규칙으로 안 잡힌다는 것을 적어 둘 것.
