# 🔴 왜 이것이 결함 후보인가 — 셋이 **`/guide`** 다

`/ecommerce/guide` · `/erp/guide` · `/scm/guide` 는 이름 그대로 **안내 화면**이다.
데이터가 아니라 «이 도메인이 무엇을 하는가» 를 설명하는 자리로 보인다.
🔴 그런 화면이 **모든 테넌트에서 권한 거부**라면 둘 중 하나다:

- **ⓐ 의도다** — 안내도 도메인 권한이 있어야 본다. 그러면 **그 의도가 어디에 적혀 있는가.**
- **ⓑ 사고다** — 안내 화면이 데이터 화면과 같은 가드를 물려받았다.

🔵 `/wms/guide` 는 **열린다**(demo-corp 에서 성공). ⇒ **같은 부류의 네 화면 중 셋만 막혔다.**
🔴 그 비대칭이 ⓑ 쪽 신호다 — 의도라면 wms 만 예외일 이유를 대야 한다.

`/tenants` 는 다른 축이다 — 테넌트 관리 화면이고, 데모 계정이 그 권한을 안 가진 것이
**정상일 수 있다.** 🔵 그러나 **그 사실이 어디에도 적혀 있지 않다**는 것이 문제다:
`TASK-MONO-648` 이 «전 페이지를 찍는다» 를 목표로 삼는 한, 못 찍는 페이지는
**「실패」가 아니라 「왜 못 찍는지」로 기록돼야** 한다.

# Scope

- 네 화면이 요구하는 권한 키를 **실측으로** 뽑는다(선언 grep 이 아니라 실제 거부 경로).
- 데모 시드가 `demo@demo.com` 에 주는 역할/권한을 **실측으로** 뽑는다.
- 둘을 대조해 **ⓐ(의도) / ⓑ(사고)** 를 가른다.
- `/wms/guide` 가 열리는 이유를 **대조군으로** 쓴다.

**Out of scope**: 권한 모델 자체의 재설계 · `ecommerce` 테넌트에서만 막히는 7개(설계대로다) ·
새 역할 신설(그건 ADR 축이다).

🔴 **권한을 넓히는 것이 기본 처방이 아니다.** 이 저장소의 분류기는 «무엇이 허용되는가» 를
바꾸는 편집을 따로 다루고, 권한 확대는 **판단이 먼저**다.

# Acceptance Criteria

## AC-0 — 착수 게이트 (전제부터 다시 재라)

- [ ] 🔴 네 경로를 **두 테넌트로 다시 열어라**. 하나라도 열리면 그 화면은 이 티켓에서 빠진다.
- [ ] 🔴 `/wms/guide` 가 **여전히 열리는지** 확인하라 — 이 티켓의 비대칭 논거가 거기 서 있다.
      🔵 그것도 막히면 논거가 «셋만 막혔다» 에서 «guide 전부가 막혔다» 로 바뀌고, 그러면
      ⓐ(의도) 쪽이 강해진다.
- [ ] 🔴 **창이 필요하다.** 못 열면 `ready/` 에 그대로 둬라.

## AC-1 — 요구 권한과 보유 권한을 **각각 실측**한다

- [ ] 화면 쪽: 거부를 내는 자리를 찾아 **권한 키 이름**을 뽑아라. 🔴 화면 문구
      (*"scm 조달 화면을 조회할 권한이 없습니다"*)는 **키가 아니다**.
- [ ] 계정 쪽: `demo@demo.com` 이 그 테넌트에서 **실제로 가진** 권한 목록을 뽑아라.
      🔵 시드 스크립트 선언이 아니라 **런타임 값**이어야 한다 — 이 저장소가 「선언 파일 grep ≠
      런타임 모집단」으로 여러 번 데인 축이다.
- [ ] 두 목록을 **나란히** 적어라. 교집합이 비는 자리가 답이다.

## AC-2 — ⓐ/ⓑ 를 가르고, ⓑ 면 **소유자에게 묻는다**

- [ ] 판정을 적어라. 🔴 ⓐ(의도)라면 **그 의도를 어디에 적을지**까지 정해라 —
      적히지 않은 의도는 다음 사람이 또 결함으로 신고한다.
- [ ] ⓑ(사고)라면 고치는 범위가 **권한 확대**이므로 **소유자 결정**이다. 물어라.
      🔴 내 추천을 결정으로 적지 마라.

## AC-3 — `TASK-MONO-648` 에 되돌려 준다

- [ ] 🔴 648 은 *"200 이 아니거나 로그인 화면으로 튕긴 경로는 실패로 센다"* 고 했고,
      *"실패 목록을 이름을 대며 보고한다"* 고 했다. **이 네 줄이 그 보고의 잔여다.**
      판정이 나면 648 의 커버리지 문장(54/58)에 **사유를 붙여** 되돌려라.
- [ ] 🔵 «54/58» 은 **게이트가 없는 숫자**다 — 라우트가 늘면 낡는다. 그 사실을 적어라.

# Edge Cases

# Failure Scenarios

1. **권한을 넓혀서 «해결» 한다** → ⓐ(의도)였다면 보안 경계를 데모 편의로 연 것이다.
2. **「데모 계정 권한 문제」로 뭉뚱그린다** → `/wms/guide` 가 열린다는 비대칭이 설명 안 된다.
3. **화면 문구를 권한 키로 읽는다** → AC-1 이 그것을 금지한다.
4. **648 에 안 되돌린다** → 커버리지 숫자는 남고 **왜 못 찍는지는 사라진다.**
