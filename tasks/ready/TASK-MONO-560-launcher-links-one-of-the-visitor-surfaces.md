# 배경 — 2026-08-19(UTC) 소유자가 직접 밟았다

기동 후 "데모 사이트 열기 →" 를 눌렀더니 404 였고(그건 **부팅 중**이라 별건이다),
그 자리에서 나온 질문이 이 티켓이다:

> *"데모사이트는 뭘 얘기하는거야? 화면보는 사이트가 이커머스, 팬, 콘솔 3개 있잖아"*

**포트폴리오 소유자 본인이 자기 데모에서 화면 두 개를 못 찾았다.** 면접관이 찾을 리 없다.

## 실측 — 링크는 정확히 하나다

`infra/demo/aws/site/index.html`:

```js
const demoHost = (ip) => `${ip.replace(/\./g, "-")}.sslip.io`;  // GUARD-T-ANCHOR
const demoUrl  = (ip) => `http://console.${demoHost(ip)}/`;     // L109
…
if (ip) $("open").href = demoUrl(ip);                            // L136
```

`<a>` 태그는 하나(`id="open"`, L57)이고 그 목적지는 **운영 콘솔뿐**이다.

Traefik 이 실제로 라우팅하는 호스트를 전수로 뽑으면 브라우저로 여는 화면은 셋이다.
같은 IP 에서 전부 200 을 확인했다(2026-08-19 12:07 UTC):

| 화면 | 호스트 | 실측 |
|---|---|---|
| 운영 콘솔 | `console.<host>/` | 200 (→ `/login?redirect=/dashboards/overview`) |
| 이커머스 스토어프런트 | `web.ecommerce.<host>/` | 200 |
| 팬 플랫폼 웹 | `web.fan-platform.<host>/` | 200 |

나머지 Host 규칙은 API 게이트웨이(`ecommerce.` `wms.` `scm.` `erp.` `finance.`
`fan-platform.` `iam.`)와 관측 도구(`grafana.iam.` `grafana.wms.` `kafka.iam.`
`kafka.wms.`) 다 — 브라우저로 "구경하는" 화면이 아니다.

## 🔴 페이지는 이미 도메인별 상태를 알고 있다

`renderDomains()` 가 도메인마다 행을 그리고 `up`/`partial` 배지와 시작/종료 버튼을
붙인다. 즉 **"이 도메인이 지금 열리는가" 를 이미 계산하고 있다.** 없는 것은 링크뿐이다.

## 🔴 그래서 링크를 그냥 박으면 안 된다

부팅에는 약 10분이 걸리고, 그 창에서 각 화면은 404 다. 안 뜬 화면에 링크를 주면
방문자는 404 를 보고 **"고장났다"** 로 읽는다 — 이번에 소유자가 겪은 것이 정확히 그
오독이다. 링크는 그 도메인이 `up` 일 때만 살아 있어야 한다.

이 티켓은 *"확정 없이 링크 3개로 넘어가면 '전부 링크했다' 고 주장하면서 하나를 빠뜨린다"* 고
막아 뒀다. 확정한다 — **답이 이미 저장소에 있었다**:

> `projects/ecommerce-microservices-platform/specs/integration/iam-integration.md:51`

> operator UI now in platform-console. Client seed retire migration deferred.**)

앱이 제거됐고 운영자 UI 는 platform-console 로 갔으며, **시드 회수 마이그레이션만 미뤄져** 있다.
⇒ 라우트가 빠진 게 아니라 **콜백이 낡은 것**이고, 화면은 더 없다.

Traefik `Host(...)` 규칙을 전수로 다시 세었고 인계 표와 같다: **브라우저 화면 3**
(`console` · `web.ecommerce` · `web.fan-platform`) · API 게이트웨이 7 · 관측 도구 4.

## AC-1~AC-3 — 링크 3개, 전부 도메인 헬스에 묶고 `demoHost()` 를 통과

🔴 **`partial` 을 비활성으로 정했다(AC-2 (3))** — 그리고 근거를 `index.html` 에 적었다.
partial 은 그 도메인의 일부가 unhealthy 라는 뜻이고 **웹 표면이 그중 하나인지 페이지는 알 수
없다.** 활성으로 두면 방문자가 눌러서 404/500 을 보고 **"고장났다"** 로 읽는다 — 이 티켓의
발견 경로가 정확히 그 오독이다. 조금 더 기다리게 하는 쪽이 잘못된 인상을 주는 쪽보다 낫다.

🔴 비활성은 흐리게 보이는 것으로 부족해서 **`href` 자체를 제거**한다(클릭도 새 탭도 없다).
🔵 링크 판정과 배지는 **같은 스냅샷**을 쓴다 — 두 출처를 두면 배지는 초록인데 링크는 죽은
(또는 그 반대) 상태가 생기고, 그건 진단이 가장 오래 걸린다.
🔵 이제 링크를 만드는 경로가 하나뿐이라 **쓰이지 않게 된 `demoUrl()` 을 지웠다**(두 번째 경로를
남기면 언젠가 갈린다).

## AC-4 — 가드 (z14): grep 이 아니라 **실행**한다

판정 로직을 `GUARD-Z14` 앵커 구간에서 뽑아 **최소 DOM 대역 위에서 node 로 돌린다**.
문자열 grep 술어는 자기 문서에 걸리기 때문이다(아래 § 함정 참조).

| 칸 | 실측 |
|---|---|
| (1) up | 셋 다 활성 + `href` 가 `demoHost()` 파생 |
| (2) down/unknown | **비활성 · `href` 없음** |
| (3) partial | 명시된 결정대로 **비활성** |
| (4) `health_stale` | state 가 전부 up 이어도 **비활성** |

**bite 8칸 전부 발화**: 링크 통째 삭제 · 속성 오타(추출 흘림) · partial 활성화 · stale 무시 ·
`href` 유지 · 코드에 sslip 하드코딩 · 없는 도메인 지칭 · 주석제거기 무력화(대조군).
전체 정적 스위트 **rc=0 · ok 60건**.

## 🔴 가드를 쓰면서 그 자리에서 물린 것 두 가지

**① 드라이버의 모집단을 하드코딩했다가 링크 삭제를 못 봤다.** node 대역의 앵커 목록을 리터럴
셋으로 적어 두었더니, 마크업에서 팬 링크를 지워도 드라이버는 여전히 셋을 테스트하고 **가드가
조용히 통과**했다. 지금은 마크업에서 뽑은 목록을 주입하고, 추가로 **추출이 한 줄을 흘리는
경우**(속성 오타)와 **화면 수 하한**(3, Traefik 전수로 확정한 값)까지 대조한다.

**② 하드코딩 검사가 자기 문서에 걸렸다.** `sslip.io` 를 찾는 grep 이 **sslip 표기 함정을
설명하는 MONO-389 주석**에 걸렸다. 주석을 걷어낸 뒤 본문만 보게 고쳤고, 걷어내기가 본문까지
먹지 않았는지 **대조군**(GUARD-T-ANCHOR 줄이 남아 있는가)을 붙였다 — 빈 입력에 대고 grep 하면
언제나 통과하기 때문이다.

낡은 것이다. **어느 쪽인지 확정하고 적어라.** 확정 없이 링크 3개로 넘어가면 이 티켓이

**AC-2 — 안 뜬 화면은 링크되지 않는다. 🔴 대조군 필수. ✅ 완료 — 네 칸 전부 가드 (z14) 가 실행으로 대조.**

# Edge Cases

- **`partial` 상태**: 도메인은 떴는데 일부 컨테이너가 아직이다. 프런트 컨테이너가
  그 "일부" 면 링크는 활성인데 404 다 — AC-2 (3)이 이걸 강제로 결정하게 한다.
- **`admin.ecommerce` 라우트 부재**: AC-0 이 확정한다. 라우트를 만드는 것은 이 티켓
  범위 밖이므로, (a)로 판명되면 **별도 티켓을 파일하고 이 티켓에서는 링크하지 않는다.**
- **API 게이트웨이/관측 도구를 링크할 것인가**: 지금은 안 한다. 다만 포트폴리오 관점에서
  Grafana/Kafka UI 는 보여줄 값이 있다 — 판단 근거를 적어 두고 넘어가라(나중에 "왜 뺐지"
  가 반복되지 않게).
- **콘솔의 로그인 리다이렉트**: 최종 200 이지만 첫 응답은 307 이다. 판정에 상태 코드를
  쓸 때 리다이렉트를 추적하지 않으면 "안 뜬다" 로 오독한다.

# Failure Scenarios

- **링크만 3개 박고 상태를 안 보면**: 부팅 10분 창 전체에서 방문자가 404 를 본다.
  이 티켓이 시작된 그 오독을 **두 배로** 만든다.
- **AC-0 을 건너뛰고 위 표를 그대로 쓰면**: `admin.ecommerce` 가 미해결로 남고,
  티켓은 "전부 링크됨" 을 주장한다 — 거짓 완결이다.
- **하드코딩 호스트로 링크를 만들면**: 이번 IP 에서는 전부 통과하고 **다음 재기동에서만**
  깨진다. 그때는 이 변경이 용의자로 안 떠오른다.
