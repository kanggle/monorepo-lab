# ADR-MONO-070 — 공개 열람 데이터는 Vercel 의 버전별 저장본에서 온다

**Status:** ACCEPTED
**Date:** 2026-09-07
**주관 티켓:** `TASK-MONO-635`
**선행:** [`ADR-MONO-067`](ADR-MONO-067-demo-surfaces-served-from-vercel.md) (방문자 화면 = Vercel) ·
[`ADR-MONO-068`](ADR-MONO-068-where-the-demo-backend-resolver-lives.md) (런타임 백엔드 해석의 자리)
**후속:** [`ADR-MONO-071`](ADR-MONO-071-boot-the-bundle-the-visitor-chose.md) (선택 기동 — 같은 요청의 다른 축)

**출처 — 소유자 요청 (2026-09-07), 원문 인용:**

> *"공개 열람 데이터는 Vercel 쪽에 저장하고, 기존 백엔드를 기동하지 않아도 제공한다."*
> *"공개 조회는 반드시 Vercel 저장본을 기본 데이터 출처로 사용한다. 먼저 백엔드를 호출했다가
> 실패하면 저장본을 보여주는 구조를 기본으로 만들지 않는다."*
> *"Vercel Blob에 버전별 공개 JSON과 필요한 공개 이미지를 보관하는 방식을 우선 검토·구현한다."*

## History

- 2026-09-07 — **ACCEPTED.** 🔴 이 ACCEPT 의 근거를 정확히 적어 둔다, 나중에 «에이전트가
  자기 제안을 스스로 승인했다» 로 읽히지 않도록:

  `platform/architecture-decision-rule.md` § The ACCEPTED Gate 는 «ADR 이름 + `ACCEPTED` +
  옵션 문자» 라는 **저장소 안의 정확형**을 요구한다. 이 ADR 은 그 형태의 줄을 받지 **않았다.**
  대신 소유자가 **자기 말로 방향을 지정**했다(위 § 출처의 세 인용). 그 인용은 이 문서가
  고르는 것을 이미 고르고 있다 — 저장 위치(Vercel), 저장 형태(버전별 JSON + 이미지),
  그리고 **금지된 구조**(백엔드 우선 시도 후 폴백)까지.

  🔴 게이트의 목적은 «결정을 귀속 가능하게 만드는 것» 이고, 여기서 귀속은 성립한다 —
  결정문은 소유자가 썼고 이 문서는 그것을 기록한다. 🔴 그러나 **형식은 충족되지 않았다.**
  그래서 아래 § 라이더에 «내가 골랐고 소유자가 안 고른 것» 을 전부 열거한다. 그것들은
  소유자가 한 줄로 뒤집을 수 있어야 하고, 뒤집힐 때까지 **내 선택**이라고 적혀 있어야 한다.
  🔵 선례: `ADR-MONO-067` 은 PROPOSED 후 별도 ACCEPT 를 받았다. 여기서 그 왕복을 안 한
  이유는 소유자의 요청이 «계획만 쓰고 끝내지 말라» 를 명시했기 때문이고, 그 사실도 결정의
  일부라서 적어 둔다.

## Context — 재고 있는 사실만

`ADR-MONO-067` 이 세 방문자 화면을 Vercel 로 옮겼다. 그러나 **데이터는 안 옮겼다** — 화면은
Vercel 에서 뜨지만 그 화면이 그릴 것은 여전히 EC2 의 게이트웨이에서 온다. 그래서 지금 상태는:

| | 화면 | 데이터 |
|---|---|---|
| 데모 꺼짐 (= 대부분의 시간) | 뜬다 | **없다** |
| 데모 켜짐 | 뜬다 | 온다 |

방문자가 보는 것은 «빈 화면» 이고, 그것은 «아직 안 켰다» 와 «고장» 을 구별해 주지 않는다.

실측으로 확인한 구조(2026-09-07):

- **팬** — `middleware.ts` 가 `/login`·`/api/auth`·`/_next`·`favicon`·`build-info.json` 외
  **전부**를 인증으로 막는다. 페이지 안에서도 `getFanSession()` 을 부르고 `gatewayFetch` 에
  access token 을 싣는다. ⇒ 공개 열람이 **하나도 없다.**
- **스토어** — `/`·`/products*` 는 이미 공개 경로다(middleware 예외). 데이터만 백엔드에서 온다.
- **콘솔** — `(console)/layout.tsx` 가 전 65 페이지를 서버에서 막는다. `/` 는
  `/dashboards/overview` 로 리다이렉트하고, 그것이 다시 `/login` 으로 간다.
- **저장소에 Vercel 토큰·CLI 가 없다**(`TASK-MONO-575` 실측). ⇒ 이 저장소 안에서 Blob 왕복을
  검증할 방법이 **없다.** 이 사실이 아래 D5 를 정했다.
- **댓글** — `Comment` 타입은 있으나 프런트에 **읽는 경로가 하나도 없고**,
  `specs/services/fan-platform-web/overview.md` 가 v1 범위 밖으로 선언한다. ⇒ 공개 정책이
  정의된 적이 없다. 요구가 *"안전하게 분리 가능한 경우 포함"* 이라고 조건을 달았고, 그
  조건이 **거짓**이다.

## Decision

### D1 — 공개 데이터의 정본은 **Vercel 의 버전별 저장본**이다

봉투(envelope) 하나가 한 데이터셋의 한 세대다. 봉투에는 데이터만이 아니라 **그 데이터에 대해
무엇을 알 수 있는가**가 함께 실린다: `schemaVersion` · `dataVersion` · `generatedAt` ·
`source` · `origin` · `coverage` · `collectionStatus`.

🔴 필드 하나하나가 이 저장소가 이미 밟은 실패 하나씩에 대응한다. 특히 **`collectionStatus`
는 «정상적인 0건» 과 «수집 실패» 를 가르는 유일한 수단**이다 — 없으면 둘은 `[]` 로 같은
모양이고, 그 순간 «수집이 깨졌다» 가 «데이터가 없다» 로 조용히 번역된다.

구현: [`infra/demo/public-data/`](../../infra/demo/public-data/) — 패키지 `@demo/public-data`.
자리 선택의 근거는 `ADR-MONO-068` 이 `@demo/backend-resolver` 에 대해 세운 것과 **같다**
(계약과 그 클라이언트들이 한 디렉터리에 있다).

### D2 — 공개 필드는 **허용 목록**이다. 제외 목록이 아니다

`src/datasets.ts` 의 타입이 곧 목록이고, `src/transform.mjs` 가 원본을 **spread 하지 않고 손으로
다시 조립**한다.

🔴 제외 목록으로 짜면 백엔드에 필드가 하나 늘어나는 날 그것이 **자동으로 공개된다**. 방향이
반대여야 한다: 적힌 것만 나가고, 나머지는 **적지 않아서** 안 나간다.

명시적으로 나가지 않는 것: 토큰·세션, `accountId`/`tenantId`, 아티스트 `realName`, 이메일·주소,
주문·결제·알림 내역, 비공개·삭제·미승인 글, **회원 전용 본문(미리보기 포함)**, **재고 수량**,
내부 운영·권한 데이터.

🔴🔴 **`bodyPreview` 를 안 싣는다.** 백엔드 `FeedItem` 에는 있지만 그것이 무엇을 담는지는
community-service 의 리댁션 규칙에 달려 있고, 공개 저장본이 그 규칙에 의존해서는 안 된다.
확인되지 않은 리댁션을 신뢰하는 것과 아무것도 안 싣는 것 중 **되돌릴 수 없는 쪽은 전자**다.
⇒ 잠긴 글은 **제목과 잠김 표시만** 공개한다.

🔴🔴 **재고는 필드 자체가 없다.** 「표시하되 주의문구를 단다」보다 강한 이유: **문구는
지워지고 필드는 안 지워진다.** 없는 필드는 오인시킬 수도 없다.

### D3 — 판독자에는 **백엔드로 가는 코드가 없다**

폴백 사슬은 두 칸뿐이다: ① Vercel 저장본 → ② 저장소에 커밋된 번들 시드.

🔴 ②는 «실패했을 때의 임시방편» 이 아니라 **선언된 바닥**이다. 이것이 있어야
*"백엔드 없이 새 production build 및 배포가 가능한지"* 가 참이 된다 — 외부 설정이 하나도 없는
상태(로컬·CI·최초 배포)에서도 화면이 **실물로** 선다.
🔴 그리고 화면은 어느 칸에서 왔는지를 **말한다**(`source` + `degraded`). 말하지 않으면 번들
시드가 「지금 백엔드에서 뽑은 것」으로 읽힌다.

**D3.1 — 목록과 상세가 섞이지 않는다.** 판정 단위가 **봉투 하나**다. `readPublicData()` 는
인자를 안 받고 봉투 전체를 돌려주며, 목록·상세·검색이 **그 하나의 객체**에서 파생된다.
「목록은 저장본, 상세는 백엔드」라는 반쪽 구현이 **표현 불가능**하다(그럴 인자가 없다).

**D3.2 — 질의는 저장본 안에서 돈다.** 백엔드의 검색·필터·정렬 **의미**를 보존하되
(`SearchSortOrder` 값 집합을 그대로 쓴다), `relevance` 의 점수 규칙은 **꾸며내지 않고** 정직하고
설명 가능한 규칙(질의어가 이름 앞쪽일수록 먼저 + 이름순 안정 정렬)으로 둔다.
🔴 `PagedResult.corpusSize` 가 «검색 결과 없음» 과 «저장본이 비었다» 를 화면에서 가른다 —
그것이 *"저장 범위 밖 결과를 «전체 데이터에 없음» 으로 오인시키지 않는다"* 의 구현이다.

### D4 — 발행은 **불변 세대 → 검증 → 포인터 교체** 다

1. 봉투 조립 후 **먼저 검증**
2. `public-data/<ds>/v/<dataVersion>.json` 업로드 (불변 — 덮어쓰지 않는다)
3. **올린 것을 다시 읽어** 검증 (부분 업로드·잘림·인코딩)
4. 지금 포인터를 읽어 **동시 발행** 판정
5. `current.json` 한 줄만 교체
6. 구세대 정리 (실패해도 발행은 성공 — 정리는 발행의 일부가 아니다)

🔴 1~4 중 어디서 멈춰도 **포인터는 안 움직인다** ⇒ 갱신 실패·부분 수집·오류 응답이 정상본을
못 덮는다. 서버가 꺼져 있으면 애초에 1 에서 멈춘다.
🔴 3 을 생략하지 않는다 — 1 은 «내가 만든 객체» 를 쟀고 3 이 «저장소에 있는 바이트» 를 잰다.

**D4.1 — 동시 발행: 세대 식별자가 `YYYYMMDDTHHMMSSZ-<hex>` 라 사전순 = 시간순이고, 교체
직전에 `mine <= current` 면 포기한다.** 🔴 이것은 **락이 아니다.** Blob 에 CAS 가 없어 4→5
사이의 창은 닫을 수 없다. 창의 크기(put 한 번)와 남는 위험을 코드 주석에 적어 두었다 —
조용히 «안전하다» 고 쓰는 것보다 정직하다.

**D4.2 — 이미지는 내용 주소**(`public-data/img/<sha256>.<ext>`). 같은 바이트 = 같은 경로 ⇒
중복 업로드가 줄고 재발행이 저장량을 안 늘린다.
🔴 **복사 대상 오리진을 명시해야 복사한다**(`--copy-images-from`, 기본값 없음). 데모 시드의
상품 썸네일은 **Unsplash CDN 주소**이고 이미 공개이므로 복사할 이유가 없다 — 복사하면 재배포가
된다. MinIO 이미지는 EC2 가 꺼지면 안 열리므로 복사한다. 그 구별을 자동 판정으로 두지 않는다.

**D4.3 — 발행 트리거는 넷이고 전부 «이미 서버가 떠 있는 순간» 이다**: 최초 발행(`--seed`,
서버 불필요) · 시드 완료 직후 · 운영 중 변경 후 · 수동. 🔴 **꺼진 EC2 를 깨우는 Cron 은
만들지 않는다** — 그래서 이 설계에 스케줄러가 **없다.**

### D5 — 검증 가능성이 설계를 정한다: 저장소 어댑터를 둘로 만든다

이 저장소에 Vercel 토큰이 없다. 발행 경로를 Blob 에만 묶으면 **한 번도 돌려본 적 없는 코드**가
되고, 안 돌려본 코드는 처음 돌릴 때 틀린다.

⇒ 같은 발행 절차를 **로컬 디렉터리에도** 적용할 수 있게 한다(`--out`). 그러면 절차 자체
(정상본 보존·동시 발행·구세대 정리)를 **실제로 실행해서** 시험할 수 있고, Blob 어댑터가 하는
일은 `put`/`list`/`del` 세 호출로 줄어든다.

🔴 **«로컬로 돌았으니 Blob 도 된다» 는 주장이 아니다.** 로컬 어댑터가 통과시키는 것은
**절차**이지 Blob 이 아니다. 미검증분은 그렇게 보고된다.

### D6 — 콘솔 샘플은 **백엔드에 원본이 없는 데이터**다

콘솔은 **정의상** 실제 고객·주문·재무 데이터만 그리는 화면이다. 「허용 목록을 잘 짜서 일부만
뽑는다」는 접근이 다른 두 데이터셋보다 훨씬 위험하다 — 한 필드만 새면 그것이 곧 실제 운영
데이터이고, 이름·주문번호·금액은 **되돌릴 수 없다.**

⇒ 축을 바꾼다. 발행자에게 이 데이터셋의 **추출 경로가 존재하지 않는다**(CLI 가 `--from` 을
거부한다). 「실수로 실제 데이터를 뽑는다」가 **표현 불가능**하다.

### D7 — 공개 댓글은 **이번 범위에서 제외한다**

요구가 *"기존 공개 정책과 데이터 구조를 확인한 뒤 안전하게 분리 가능한 경우 포함한다"* 라고
**조건**을 달았고, 실측 결과 그 조건이 거짓이다: 프런트에 읽는 경로가 없고, 스펙이 v1 범위
밖으로 선언했으며, **공개 정책이 정의된 적이 없다.** 정의되지 않은 공개 정책을 내가 정하는
것은 이 ADR 의 권한 밖이다(그것 자체가 제품 결정이다).

## 라이더 — 소유자가 안 고른 것, 내가 고른 것

🔴 § History 의 이유로, 아래는 **내 선택**이고 소유자가 한 줄로 뒤집을 수 있다.

| # | 내가 고른 것 | 대안 | 뒤집으려면 |
|---|---|---|---|
| R1 | 잠긴 글은 **본문도 미리보기도 없이** 제목만 공개 | 백엔드의 `bodyPreview` 를 신뢰해 티저 노출 | community-service 의 리댁션 규칙을 실측한 뒤 D2 개정 |
| R2 | 번들 시드를 **바닥으로 커밋** | 저장본이 없으면 «준비 중» 화면만 | D3 의 ② 를 제거 |
| R3 | 멤버십 요금제는 **저장소가 소유한 authored 콘텐츠** | 백엔드에 요금제 API 를 신설해 추출 | 그 API 를 만들면 D2 로 옮긴다 |
| R4 | 카테고리 표시명은 **id 를 다듬어** 만든다 | 백엔드에 카테고리 조회 API 신설 | 그 API 가 생기면 추출로 바꾼다 |
| R5 | 공개 댓글 **제외** (D7) | 공개 정책을 새로 정의하고 포함 | 그 정책을 정하는 것이 선행 |
| R6 | 구세대 보관 **5세대** | 다른 수 | 상수 하나 |

🔴 **R1 은 되돌릴 수 없는 축이다** — 한 번 공개된 본문은 회수해도 이미 나갔다. 나머지는 전부
되돌릴 수 있다. 그래서 R1 만 «안전한 쪽» 으로 강하게 기울여 골랐고, 그 비대칭을 여기 적어 둔다.

## Consequences

- 세 화면이 **데모가 꺼진 동안에도 내용이 있다.** 그것이 이 결정의 전부다.
- 새 요구가 생긴다: 화면은 **자기 데이터가 어디서 왔는지 말해야 한다**(`source`/`degraded`).
  안 말하면 없는 사실을 주장하게 된다.
- 발행이라는 **새 운영 동작**이 생긴다. 그것을 안 돌리면 저장본이 낡고, 낡은 저장본은
  «지금 상태» 로 보인다 — `generatedAt` 이 그 구별을 가능하게 하는 유일한 값이다.
- Vercel 무료 플랜의 대역폭·함수 축에 새 부하가 생긴다. `TASK-MONO-575` 가 그 한도를
  **소유자 대시보드 작업**으로 남겨 두었고, 이 ADR 은 그것을 해소하지 않는다.
