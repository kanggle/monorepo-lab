# infra/demo/idp-advertised-path-prefixes.txt — IdP 의 discovery 문서가 광고하는 경로 접두사
# =============================================================================
# TASK-MONO-615 B1 (근거: TASK-MONO-610 기동 창 V4).
#
# 무엇인가
# -----------------------------------------------------------------------------
# `/.well-known/openid-configuration` 의 **URL 값 필드**(`*_endpoint` · `*_uri`)에서
# 경로의 **첫 세그먼트**만 뽑은 집합이다. `infra/demo/iam-traefik.override.yml` 의
# `iam-oidc` 라우터가 이 전부를 `PathPrefix` 로 덮어야 한다.
#
# 🔴 왜 파일로 두는가 — 이 저장소가 이미 겪은 결함이 **두 번**이다
# -----------------------------------------------------------------------------
#   TASK-MONO-380: `/signup` 이 빠졌다 → 로그인 폼이 스스로 거는 링크가 404.
#   TASK-MONO-610: `/connect` 가 빠졌다 → discovery 가 광고하는 로그아웃이 404.
# 두 번 다 **컨테이너는 전부 healthy** 하고 **로그인은 되는데** 한 경로만 죽었다.
# 손으로 열거하는 목록은 다음 엔드포인트에서 또 드리프트한다.
#
# 🔴🔴 손으로 타이핑하지 마라 — **라이브 문서에서 받아 적어라**
# -----------------------------------------------------------------------------
# 재파생 (데모가 떠 있을 때):
#
#   curl -s "http://iam.${DEMO_DOMAIN}/.well-known/openid-configuration" \
#     | python -c "import sys,json,urllib.parse as u; d=json.load(sys.stdin); \
#         print('\n'.join(sorted({'/'+u.urlparse(v).path.strip('/').split('/')[0] \
#           for v in d.values() if isinstance(v,str) and v.startswith('http') \
#           and u.urlparse(v).path.strip('/')})))"
#
# 가드 (z20)(정적)은 「라우터 ⊇ 이 파일」을, 가드 (z21)(`--live`)은 「라이브 문서 == 이
# 파일」을 잰다. (z21)이 새 접두사를 발견하면 **FAIL 이다** — 이 핀이 낡았다는 뜻이고,
# 그 상태에서 (z20)만 초록인 것은 「덮었다」가 아니라 **「덜 알고 있다」**이기 때문이다.
#
# 🔵 여기 없는 것과 그 이유
# -----------------------------------------------------------------------------
#   `/.well-known` — discovery 문서가 **자기 자신을 광고하지는 않는다**. 그러나 그것이
#                    안 라우팅되면 이 파일을 만들 수조차 없으므로 (z20)이 **따로** 단언한다.
#   `/login` `/signup` — OIDC 가 아니라 폼 로그인 표면이다. 가드 (p) 가 로그인 템플릿의
#                    링크에서 파생해 지킨다(TASK-MONO-380). 여기서 중복해 세지 않는다.
#
# 🔴 출처 기록 (provenance)
# -----------------------------------------------------------------------------
#   2026-09-02 UTC · TASK-MONO-610 기동 창 · 데모 호스트 `iam.43-202-166-3.sslip.io`
#   관측한 필드: issuer · authorization_endpoint · device_authorization_endpoint ·
#                token_endpoint · jwks_uri · userinfo_endpoint · end_session_endpoint ·
#                revocation_endpoint
#   🔴 그 세션은 문서의 **앞부분만** 읽었다(1,587B 중 약 900B). 따라서 이 목록은
#      「관측된 접두사 전부」이지 **「문서가 광고하는 접두사 전부라고 증명된 것」이 아니다.**
#      완전성은 (z21)이 라이브에서 강제한다 — 새 접두사가 나오면 FAIL 이고, 그때
#      이 파일을 **다시 받아 적어라**(추가로 타이핑하지 말고 위 명령의 출력으로 덮어라).
